# Маска XYZ для Unity

Готовая игровая сцена: `Assets/Scenes/MaskDemo.unity`. Откройте её и нажмите Play. Кнопка «МАСКА» или клавиша M включает и выключает маску. Клавиша 1 переключает X/-X, клавиша 2 — Y/-Y, клавиша 3 — Z/-Z. На экране этим осям соответствуют три кнопки. Повторное нажатие на ту же ось меняет знак направления. Красная X-стена исчезает при надевании маски, оставляя непрерывный проход. Исходная `SampleScene` не затронута.

Перетащите `Generated/MaskXYZ.prefab` в сцену или сделайте его дочерним объектом головы персонажа. Высота маски — 0,26 единицы Unity (метра при стандартном масштабе). Лицевая сторона направлена вдоль локальной оси `+Z`. Прорези для глаз проходят сквозь обе части модели.

Префаб содержит два материала: чёрная основа с символами X/Y/Z и белая лицевая пластина. Маска слегка изогнута вокруг лица: середина выступает примерно на 2,2 см относительно боковых краёв. Геометрия построена по приложенному изображению и допускает близкий ракурс, хотя исходник был одним видом, поэтому обратная сторона сделана простой.

`MaskAxisCamera.cs` — необязательный контроллер механики шести видов. Добавьте его на объект сцены, назначьте `Target Camera`, `Focus` и блокирующую стену в `Walls Hidden By Mask`. Вызовите `EquipMask()` при надевании. Три кнопки UI подключаются к методам `PressX`, `PressY`, `PressZ`. Повторное нажатие кнопки той же оси меняет знак направления. При старом Input Manager также работают клавиши 1, 2, 3.

Если проект использует другой рендер-пайплайн и материалы отображаются розовыми, выполните `Tools > Mask XYZ > Rebuild Mask Prefab`: материалы будут пересозданы для доступного Lit-шейдера.

TUTORIAL 2 — ОФИС В ДВУХ ВРЕМЕНАХ

OfficeTwoWorlds.prefab добавлен в Level02_Tutorial. Первый уровень не меняется.

Без маски: разрушенный, заросший офис, открытые участки потолка, папоротники,
лианы и корни. В маске: чистый современный офис, целый потолок, тёплый свет.
Смена оформления происходит через событие MaskStateChanged, когда глаза закрыты.

Механика:
1. Первая стена — корни. Маска убирает их и открывает проход.
2. Первый провал — мост из корней существует только без маски.
3. Вторая стена существует в офисе. Сними маску, чтобы пройти. Боковая дверь закрыта.
4. Второй провал — обычный пол существует только в маске.
Возвращение стены внутри игрока и возрождение на шаг назад работают как раньше.

НАСТРОЙКА
В префабе три группы:
01 Architecture and wayfinding — общие указатели.
02 Overgrown - MASK OFF — заросли, разрушенная мебель, свет без маски.
03 Restored office - MASK ON — чистая мебель, архитектура, тёплый свет.

InversionOfficeWorld: Preview With Mask переключает вид в редакторе.
В игре состояние задаёт маска, это поле не отменяет механику.
Materials — общие материалы отделки и растений; Meshes — сохранённая геометрия.
Растения и мебель декоративные, без дополнительных коллайдеров.
Проходы/смерть/мосты контролируют исходные MaskInversionGate.
Корни первой стены заменяют внешний вид её блока. Оба моста — самостоятельные префабы.

Tools > Mask Inversion > Environment > Build Two Worlds Prefab пересоздаёт
оформление по коду InversionOfficeBuilder.cs. Использовать после сохранения
своих ручных изменений: пересборка заменяет содержимое префаба.
При переносе моста перемещай корень префаба: меш, материал, коллайдер и логика находятся вместе.

ОКНА И НОЧЬ
В маске окна прозрачные: за ними есть внешний вид города и направленный дневной свет.
Без маски — ночь, слабый лунный свет, зелёные светлячки и лёгкие частицы дымки.
Оба состояния переключаются под закрытыми глазами, вместе с маской.

InversionOfficeWorld: Abandoned Ambient / Restored Ambient — общая яркость;
Night Fog Color / Night Fog Density — цвет и плотность ночной дымки.
В каждой группе мира: Atmosphere - windows and exterior.
Fireflies — количество, размер и движение светлячков (Particle System).
Green night wisps — мягкая зелёная дымка. Soft firefly bounce — локальные огоньки.
Transparent daylight glazing.mat — прозрачность стекла (Base Color / Alpha).
Sunlight through window — сила света через каждое окно.
Исходные боковые коллайдеры сохранены: окна не являются выходами из уровня.

Tools > Mask Inversion > Environment > Update Windows and Night обновляет только
окна, наружный декор и свет. Это заменяет ручные настройки этих элементов;
для обычной настройки достаточно редактировать префаб, без запуска команды.

МОСТЫ И ОПТИМИЗАЦИЯ
Assets/MaskInversion/Bridges/RootBridge.prefab — первый мост, без маски.
Assets/MaskInversion/Bridges/OfficeBridge.prefab — второй мост, в маске.
Каждый префаб содержит меш, материалы, BoxCollider и MaskInversionGate.
Корни объединены в один меш с четырьмя материалами. Для перемещения выбирай
корень префаба. Exists With Mask On меняет состояние существования моста.

Статичный декор объединён по материалам и 8-метровым секциям.
CombinedScenery.asset хранит объединённые меши. Число MeshRenderer: 1335 -> 275.
Стекло, текст, свет и частицы сохранены отдельно, чтобы правильно переключаться.
Оригинальные меши оставлены как исходники для пересборки и ручной работы.
Tools > Mask Inversion > Environment > Optimize Static Scenery объединяет
статичные детали префаба. Объединённые группы можно двигать целиком; для редактирования
отдельных исходных деталей используй пересборку Build Two Worlds Prefab.

SHIELD MASK — 3D-АССЕТ ДЛЯ UNITY

Импорт: Assets > Import Package > Custom Package.

Prefabs/ShieldMask.prefab — Universal Render Pipeline (URP).
Prefabs/ShieldMask_BuiltIn.prefab — Built-in Render Pipeline.
Перетащите подходящий префаб в сцену или на объект головы персонажа.

Изогнутый корпус, объёмные белые полосы и центральный щит.
Обе глазницы вырезаны насквозь в корпусе и орнаменте.
Белые выступы во внутренних уголках глаз удалены.

Высота: 26 см. Толщина корпуса: 4 мм. Изгиб по ширине: 30 мм.
Y — вверх; лицевая сторона направлена по +Z.
Чёрные и белые части используют отдельные редактируемые материалы.
В Source находятся OBJ, MTL, геометрия JSON и векторная схема.

Собрано в Unity 6000.6.0f1. HDRP-материалы не включены.
Коллайдер и привязку к персонажу настройте под вашу игровую механику.
